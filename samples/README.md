# 재현 가능한 분석 fixture

`steady-2km.gpx`는 적도에서 0.0005도 경도를 20초마다 이동하는 합성 테스트 트랙입니다. 41개 포인트, 이론 거리 약 2.2239 km, 시간 800초, 페이스 약 359.73초/km, 일정 심박 140 bpm. 고도는 포인트마다 0.5m 상승합니다. 생성 시각은 2026-01-01로 고정됩니다.

실제 사용자 기록이 아니며 자동으로 계정에 삽입하지 않습니다. 업로드하면 '샘플' 운동 날짜로 분석되며 최근 훈련 근거에서 제외됩니다. 데이터 생성 스크립트 `scripts/generate-sample.py`를 제공합니다.

## FIT 러닝 다이내믹스 fixture

`running-dynamics.fit` 역시 합성 테스트 자료입니다. FIT SDK 필드 정의와 CRC를 사용하며 1.5km/600초, 케이던스 166spm, 파워 276W, 보폭 0.96m, 수직 진동 8.4cm, 비율 8.8%, 접지 259ms를 기록합니다. `python scripts/generate-fit-sample.py`로 재생성합니다. 기기 요약 elapsed 610초와 계산값 600초를 구분합니다. GPX fixture와 마찬가지로 고정 과거 날짜라 최근 훈련 근거에 포함되지 않습니다.
