# Running Coach PRD v1

초기 14명 베타를 위한 모바일 우선 PWA. 여러 크루에 가입하는 일반 러너까지 같은 권한 모델로 확장한다. 표시되는 운동 수치는 업로드한 GPX에서 계산한다. 빈 계정에는 빈 상태만 표시하며 샘플 파일은 테스트용임을 명시한다.

## 사용자 흐름과 수용 기준

1. 이메일 가입/로그인/로그아웃, 프로필(표시 이름, 목표 거리·시간, 주당 달리기 횟수) 설정. 운영 인증은 Supabase, 로컬 인증은 명시적 개발 모드에서만 제공한다.
2. 크루 생성자는 owner. owner/admin은 만료되는 초대 코드를 발급하고 가입 요청을 승인/거절한다. owner만 관리자 지정 가능. 회원은 여러 크루에 가입 가능. 마지막 owner는 탈퇴 전에 소유권을 양도한다.
3. 최대 10 MiB GPX 업로드 → queued → processing → completed/failed. 파일 크기/XML/위경도/시각 검증. 지속성 있는 DB 작업 큐, 재시작 복구, 제한된 재시도. 실패 사유 표시. 같은 파일의 중복 업로드는 기존 기록을 반환한다.
4. 구간 연결 없이 거리 계산, GPS 급변 제외, 누락/불일치 경고. 이동/경과 시간, 페이스, 거리별 split, 심박 평균/coverage, 고도 변화와 시계열. 시간 없는 GPX는 거리는 계산하되 페이스·코칭 부하는 추정하지 않는다.
5. 최근 28일 완료 기록·목표·최근 주간량으로 결정론적인 7일 계획 생성. 근거/제약/회복 안내 표시. 완료 체크와 실제 운동 기록 연결. 외부 LLM 없이 작동. 의료 진단/부상 치료 제외.
6. 개인 대시보드: 실제 누적 거리, 주간 거리 그래프, 분석 상세, 처리 상태. 크루 대시보드: 현재 동의한 회원의 최근 28일 요약만 제공. 운영자에게 원본/개인 상세 열람권을 부여하지 않는다.
7. 크루별 동의 ON/OFF. 동의 철회 즉시 조회 제한. 원본 GPX 비공개. 개별 파일 삭제 시 분석 기록도 삭제. ZIP 내보내기, 계정 삭제 및 소유 데이터 제거.
8. 설치 manifest와 아이콘, 오프라인 안내. 인증된 API·운동 데이터는 service worker에 캐시하지 않는다.

## 범위와 운영 기준

베타는 이메일/비밀번호, GPX, 규칙 코칭, 일반 초대 코드 방식이다. 결제/웨어러블 자동동기화/경기 기록 인증/의료 서비스는 범위 밖. 초대는 코드를 앱 내에서 전달하며 이메일 자동 발송은 포함하지 않는다. Supabase 인증 이메일은 프로젝트 SMTP 설정이 필요하다.

성공 지표: 14명 가입·GPX 처리·공유 동의 검증, 정상 GPX 처리 성공률 95% 이상, 10 MiB 이내 입력의 처리시간 모니터링, 다른 회원의 상세 데이터 접근 차단. 수치 정확도는 알려진 좌표/시간 fixture와 오차 범위로 검증. 보안 검증을 완료하고 모니터링·복구 담당자를 지정한 후 실제 개인정보를 투입한다.
