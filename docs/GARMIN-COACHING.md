# 상세 기록·기록 기반 코치·훈련 편집

## 데이터 출처

GPX, FIT, FIT 하나가 들어 있는 ZIP을 업로드합니다. ZIP은 디스크에 풀지 않고 크기·개수·압축률·암호화를 검증합니다. FIT는 CRC를 검사하며 러닝·걷기 단일 활동과 GPS 없는 실내 러닝의 기기 거리를 지원합니다. 멀티스포츠는 활동별로 내보내야 합니다.

파일에 있는 케이던스·파워·보폭·수직 진동/비율·접지 시간/좌측 비율·센서 온도·기기 랩을 표시합니다. FIT 원본 요약과 앱의 거리/시간/페이스 계산은 별도로 표시합니다. 기기 모델·펌웨어·파일 형식에 따라 제공 범위가 다릅니다.

- FIT cadence(rpm)는 러닝 보행 주기당 두 걸음으로 steps/min에 환산합니다. step_length(mm)는 m, vertical_oscillation(mm)는 cm로 변환합니다.
- GPX Garmin cad가 30~125이면 보행 주기로 해석해 2배 환산하고 경고를 표시합니다. 소스마다 단위가 다르면 원본을 확인해야 합니다.
- 바디 배터리·수분 손실·경사 조정 페이스·기본 운동 효과 분류 등 원본에 없는 지표를 추정하지 않습니다. 사용자가 직접 옮겨 적으면 ‘직접 기록’으로 구분합니다.
- Garmin Connect 계정 자동 동기화 및 독자 알고리즘 재현은 제공하지 않습니다. 자동 동기화에는 별도의 공식 Garmin Health/Activity API 권한이 필요합니다.

시간/거리 가로축과 페이스/속도 선택, 동기화된 그래프 포인터를 제공합니다. 본인 GPS 경로는 별도 소유권 검사를 거쳐 조회하고 외부 지도 서버에 보내지 않습니다. GPS는 분석 요약/코칭 입력에 포함하지 않습니다.

## 코칭과 훈련

수치 엔진과 해설은 분리됩니다. 기본 코치는 외부 LLM 없이 재현 가능한 규칙으로 잘된 점·확인할 점·다음 훈련을 작성하며 근거를 표시합니다. 페이스 변동, 후반 구간 변화, 충분한 표본이 있는 심박/속도 변화, 훈련 의도와 RPE를 사용합니다. 심박 변화로 건강 상태나 유산소 능력을 진단하지 않습니다.

이지런·인터벌·템포런·지속주·LSD·회복을 요일별로 선택합니다. 인터벌은 반복 거리/횟수, 회복 거리와 워밍업/쿨다운을 합산합니다. 템포런은 본훈련 외에 워밍업/쿨다운 10분씩을 표시합니다. 완료된 훈련은 완료를 취소한 뒤 편집합니다. API와 PostgreSQL trigger 양쪽에서 확인합니다.

추천 근거는 목표 기록이 아니라 **실제 5K/10K 기록과 최근 훈련**입니다.

- 180일 이내 실제 기록을 Riegel 지수 1.06으로 5K 참고 페이스에 환산합니다. 두 결과가 다르면 느린 결과를 사용합니다. 배율은 시작 가이드이며 정밀 운동생리 검사가 아닙니다.
- 실제 경기 기록이 없으면 최근 90일 1.5km 이상 유효한 러닝 3회 이상의 빠른 쪽 사분위를 사용하고 낮은 신뢰도를 표시합니다. 이지런 평균으로 경기 능력을 확정하지 않습니다.
- 기록이 부족하면 숫자를 만들지 않고 RPE를 제공합니다. 범위를 수동 입력할 수도 있습니다.
- 심박 목표는 직접 설정한 최대심박/역치심박에서만 계산합니다. 나이 공식이나 최고 관측 심박으로 최대심박을 자동 결정하지 않습니다.
- 자동 주간 계획의 최대 5% 거리 증가 기준과 최근 최장 거리 대비 하루 110% 상한을 적용합니다. 충분한 이력이 있을 때 지속주/LSD를 구분합니다. 고강도 편집은 최근 28일 6회·3개 주·7일 10km 미달 시 기반 부족 경고를 표시합니다.
- 편집한 주간 거리 초과, 연속 고강도 및 최근 최장 거리보다 10% 이상 긴 LSD에 경고를 표시합니다. 시간 훈련과 템포 워밍업의 추가 거리를 명시합니다.

## 개인 API

| API | 동작 |
|---|---|
| PATCH /profile/athlete-settings | 실제 기록/날짜, 최대·역치 심박 |
| GET /training/catalog | 종류별 추천 범위, 근거, 신뢰도 |
| GET /runs/{id}/feedback | 코칭과 심박 영역 |
| PATCH /runs/{id}/notes | 훈련 의도·RPE·메모·가민 직접 기록 |
| GET /runs/{id}/route | 본인에게만 경로 개요 제공 |
| POST /runs/{id}/reanalyze | 원본 재분석 큐 등록 |
| PATCH /plans/{id}/days/{0..6} | 종류·거리·시간·단계·목표 편집 |

모두 인증·소유권 검사·RLS를 적용합니다. 크루 운영자는 개인 상세 지표, RPE, 코칭, GPS에 자동 접근할 수 없습니다. GPX 내보내기는 기존 gpx/ 폴더, FIT는 fit/ 폴더를 사용합니다.

## 기존 운영 프로젝트 업그레이드

1. 운영 코드 배포 **전에** [202610130002_garmin_coaching.sql](../supabase/migrations/202610130002_garmin_coaching.sql)을 Supabase SQL Editor로 적용합니다. initial.sql을 재실행하지 않습니다. 기존 데이터를 삭제하지 않고 JSON 열·권한·파일 경로 제한·재분석 함수를 추가합니다.
2. API와 앱을 함께 배포합니다. 기존 Render 환경 변수/명령 및 Vercel API_INTERNAL_URL은 유지합니다.
3. 1.0.1 기록은 ‘상세 지표 재분석’ 버튼으로 기존 원본을 다시 처리합니다. GPX에 없는 FIT 지표를 자동 복원하지 않습니다.
4. 실제 Garmin FIT의 단위/기기 요약 비교, 코칭, 훈련 편집·완료 제한, 다른 사용자/운영자 차단, 원본·ZIP·삭제를 확인합니다.
